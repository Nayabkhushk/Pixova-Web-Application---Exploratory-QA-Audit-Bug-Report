# Pixova Web Application - Exploratory QA Audit & Bug Report

## 📌 Repository Description
> Detailed Quality Assurance (QA) exploratory audit and functional testing report for the Pixova web platform, demonstrating end-to-end defect detection, responsive UI analysis, and business-risk-focused severity categorization.

---

## 🎯 Executive Summary (Google XYZ Formula)

- **Accomplished (X):** Identified and documented **6 critical UI, functional, and layout defects** on the live Pixova platform during an exploratory application audit.
- **Measured By (Y):** Zeroed in on a **100% loss in primary conversion pathways** (unresponsive "Start a Project" and "Get Consultation" lead-capture buttons) and mobile layout cutoffs across varying screen dimensions.
- **By Doing (Z):** Executed structured **Exploratory Testing**, **Cross-Device Responsiveness Checks**, and **UI/UX Audits**, compiling findings into a standardized, business-impact-prioritized bug report.

## 🔍 Audit Scope & Testing Types

| Testing Category | Focus Area | Impact Evaluated |
| :--- | :--- | :--- |
| **Exploratory Testing** | Uncovered unscripted edge cases and broken interactive components. | User journey friction and navigation flow failures. |
| **Functional Testing** | Validated interactive elements (buttons, forms, links, anchors). | Primary Lead-Generation & CTA reliability. |

## 🐛 Defect Summary & Severity Analysis

| Bug ID | Defect Title | Impact & Severity | Business Risk |
| :--- | :--- | :--- | :--- |
| **BUG-001** | Mobile Display Layout Cut Off | **HIGH** | Reduces mobile user retention and degrades overall visual experience. |
| **BUG-002** | Placeholder Text in Testimonials | **MEDIUM** | Weakens brand trust due to dummy text (`when an unknown printer...`). |
| **BUG-003** | Unresponsive 'Start a Project' & Social Icons | **CRITICAL** | Directly blocks inbound client inquiries, causing revenue loss. |
| **BUG-004** | Inactive Footer Legal Links | **HIGH** | Exposes site to compliance and legal trust risks. |
| **BUG-005** | Consultation Buttons Scroll to Top | **HIGH** | Causes user drop-off by breaking conversion forms. |
| **BUG-006** | Hardcoded Service Labels & Broken Sub-Links | **HIGH** | Confuses users with mislabeled CTAs and dead links. |
